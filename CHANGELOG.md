Changelog
=========

Changes to this project are documented in one file per major version. You may browse a formatted and hyperlinked version at <https://unpoly.com/changes>.

If you're upgrading from an older Unpoly version, you should load [`unpoly-migrate.js`](https://unpoly.com/changes/upgrading) to polyfill deprecated APIs. Changes handled by `unpoly-migrate.js` are not considered breaking changes.

- [Changes in Unpoly 0.x](https://github.com/unpoly/unpoly/blob/master/docs/changes/CHANGELOG_0.x.md)
