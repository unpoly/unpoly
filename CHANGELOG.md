Changelog
=========

Changes to this project are documented at <https://unpoly.com/changes>.

The raw release notes live in [`docs/changes/`](https://github.com/unpoly/unpoly/tree/master/docs/changes), one file per major version.

Coding agents can upgrade Unpoly for you, unattended. Give your agent the [Unpoly skill](https://unpoly.com/learn/skill). It contains the release notes of every version.
