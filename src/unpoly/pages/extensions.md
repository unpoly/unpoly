Extensions
==========

Unpoly works without extensions: no server library, no build step, no CSS framework.
This chapter collects the optional tooling around the core, for when it saves you work.


Agent skill
-----------

Unpoly's documentation is available as an agent skill for AI coding tools.

<p class="read-more"><a href="/skill">Read more: Agent skill</a></p>


Protocol implementations
------------------------

Your server can inspect and manipulate Unpoly's rendering through simple
[HTTP headers](/up.protocol). Libraries implementing this protocol exist for
many languages and frameworks, like Rails, Django, Laravel or Phoenix.

<p class="read-more"><a href="/protocol-implementations">Read more: Protocol implementations</a></p>


Supporting legacy browsers
--------------------------

Unpoly supports all modern browsers out of the box. On older browsers your app
degrades gracefully, and a transpiled build covers old build tools.

<p class="read-more"><a href="/legacy-browsers">Read more: Supporting legacy browsers</a></p>


Bootstrap integration
---------------------

Optional files configure Unpoly to use Bootstrap's CSS classes for navigation
feedback, form validation and overlays. Builds exist for Bootstrap 3, 4 and 5.

<p class="read-more"><a href="/bootstrap-integration">Read more: Bootstrap integration</a></p>
