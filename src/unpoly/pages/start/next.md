Where to go from here
=====================

You have seen Unpoly's basic moves. Where you continue depends on what
you want to do next.


Continue with the chapters
--------------------------

This guide continues with one chapter per topic, beginning with [[links]].
Read them in order using the next-page links, or jump to the topic your
next feature needs. Every page stands on its own.


Look up any feature
-------------------

Every attribute, function, event and header has its own page in the
[API reference](/api), covering all options and edge cases.
To find a feature quickly, press `/` and search.


See a complete example app
--------------------------

The [demo app](https://demo.unpoly.com) shows many Unpoly patterns working
together in a real application. Its [source code](https://github.com/unpoly/unpoly-demo)
is on GitHub.


Start with one screen
---------------------

You don't need to convert your whole app at once. Unpoly enhances individual
elements, so you can start with a single link or form. Screens without Unpoly
attributes keep making full page loads, and both can coexist for as long as
the migration takes.

When you are ready to go all in, configure Unpoly to handle
[all links](/handling-all-links) and [all forms](/handling-all-forms)
without annotating each element.
