Where to go from here
=====================

That's the whole Getting started chapter. Here is how to continue.


See a complete app
------------------

The [demo app](https://demo.unpoly.com) is a small Rails application built
with Unpoly. Click around to see how it navigates without full page loads.
Its [source code](https://github.com/unpoly/unpoly-demo) is on GitHub,
so you can check how any screen is made.


Start with one screen
---------------------

You don't need to convert your whole app at once. Unpoly enhances individual
elements, so you can begin with a single link or form. Screens without Unpoly
attributes keep making full page loads, and **both can coexist** for as long
as the migration takes.

When you are ready to go all in, configure Unpoly to handle
[all links](/handling-all-links) and [all forms](/handling-all-forms)
without annotating each element.


Continue with the Links chapter
-------------------------------

The rest of this guide is one chapter per topic, beginning with [[links]].
